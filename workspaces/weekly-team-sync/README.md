# Weekly Team Sync Workspace

Use this workspace to run a focused weekly team sync with preparation, decisions, actions, and follow-through.

## Best For

- team leads
- project managers
- chiefs of staff
- small teams without a formal PMO

## Included Files

- `01-prepare-agenda.md` - agenda, pre-work, decisions, and discussion structure
- `02-track-actions.md` - action log, decision log, and follow-up prompts

## Recommended Skills

- `codexkit-meeting-summary-generator`
- `codexkit-meeting-action-router`
- `codexkit-status-update-packager`
- `codexkit-email-composer`
