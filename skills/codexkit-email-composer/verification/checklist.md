# 4C Verification Checklist - Email Composer

Use this checklist before treating an email draft as ready to send.

## Correctness - Is it right?

- [ ] Names, company names, dates, prices, links, and commitments match the user's input.
- [ ] The subject line accurately previews the email's purpose.
- [ ] Any quoted or summarized prior message is represented faithfully.
- [ ] No legal, HR, pricing, or delivery commitment is invented.

## Completeness - Is it done?

- [ ] The email includes subject, greeting, context, body, next step, and close when appropriate.
- [ ] The primary ask or message is clear within the first few sentences.
- [ ] Required attachments, links, CCs, or references are mentioned if provided.
- [ ] Deadline or response expectation is stated when action is needed.

## Context-fit - Does it match?

- [ ] Tone matches recipient relationship: internal, client, vendor, executive, or peer.
- [ ] Length fits the channel and stakes.
- [ ] The email is direct enough for busy readers and polite enough for the relationship.
- [ ] Optional shorter Slack/chat variant is included when useful.

## Consequence - Is it safe to use?

- [ ] Could this wording escalate conflict unnecessarily?
- [ ] Could the email create an unintended promise, admission, or contractual interpretation?
- [ ] Should a manager, HR, legal, finance, or comms reviewer approve it first?
- [ ] If forwarded outside the intended audience, would it create avoidable risk?

Final check: what is the single sentence most likely to be misread?
