# Common Mistakes - Performance Review Writer

## 1. Vague praise

**What goes wrong:** "Great team player" gives no evidence.

**Fix:** Name the situation, behavior, and business impact.

## 2. Personality criticism

**What goes wrong:** "Needs to be more proactive" is vague and can feel personal.

**Fix:** Describe the observable behavior and expectation.

## 3. Recency bias

**What goes wrong:** The review focuses only on the last project or last mistake.

**Fix:** Check the full review period and prior goals.

## 4. No manager support

**What goes wrong:** Goals are assigned without support or checkpoints.

**Fix:** Include manager actions, resources, and follow-up cadence.
